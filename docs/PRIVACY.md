# 数据与隐私说明

> 本插件为本地优先设计：**不联网、无遥测、不删除文件**。下面写清"读什么、写什么、什么时候会外发"。

## 一、数据放在哪

默认数据目录：`~/.dsh-session-steward/data`（Windows：`C:\Users\<你>\.dsh-session-steward\data`）。

解析顺序：配置 `dataDir` → 指针文件 `~/.dsh-session-steward/datadir.txt` → 默认目录。
"使用过的目录"会写进指针，重启不漂移。

| 文件 / 目录 | 内容 |
|---|---|
| `待办.json` | 待办台账（标题、状态、优先级、截止日） |
| `任务.json` | 共享任务板（`K-xxx`：标题、负责角色、状态、事实底稿） |
| `审计.jsonl` | 操作审计（动作、结果、时间；不含聊天正文） |
| `采集.json` / `看板.json` / `状态.json` / 各 `*状态.json` | 会话元数据快照与看板派生状态 |
| `<角色>/对话/<日期>.md` | 各角色当日对话存档（你与角色的问答） |
| `<角色>/回复/<时间>.md` | 超长回答落档 |
| `记忆/用户画像.md`、`记忆/近期交代.md`、`记忆/长期规划.md`、`记忆/情绪与处境.md` | 长期记忆四文件：规则生成的 Markdown；只读**插件自己写的本地文件**（台账/任务板、`<角色>/对话/*.md`、`史官/言行录`），不直接读宿主原始会话正文；`<!-- AUTO:START/END -->` 自动区外的内容由你手写、周更不动 |
| `记忆/状态.json` | 记忆周更时间（lastUpdatedAt）与计数 |
| `<数据目录上级>/史官/言行录/<月>/<日>.md` | 史官产出（带引用的记录） |
| `<数据目录上级>/CEO/交接卡/` | CEO 生成的交接卡 |
| `~/.dsh-session-steward/datadir.txt` | 数据目录指针（一行路径） |

**备份**：直接复制数据目录即可；**清空**：先退出 DSH，删除数据目录（或改 `dataDir` 指向新目录）。

## 二、读什么

| 场景 | 读取范围 | 默认 |
|---|---|---|
| 看板 / 采集 | 会话**标题、状态、未读数**等元数据，**不读正文** | 开 |
| 史官 | **0.47.0 发布默认读全部会话正文**（`enabled.historian: true` + `scope.mode: all`）；每条按档位/预算截取并脱敏。切回 `sandbox` 则只读 `[实验]` 前缀会话 + 三个角色会话 | 开（可关/可切 sandbox） |
| 角色聊天 | 你发进聊天框的原话会发进**绑定的真实会话**，回复也从该会话取；本地只读台账 / 任务板摘要用于说明 |
| 长期记忆 | 只读数据目录内的 `记忆/` 四文件（摘要片段进秘书 / CEO 对话）；周更来源仅限插件自己写的台账/任务板、`<角色>/对话/*.md`、`史官/言行录`，不直接读宿主原始会话正文；史官不读记忆 | 开（可手工编辑文件；自动区外手写不会被覆盖） |
| 找文件 | 只在 `find.allowedRoots`（默认数据目录上一级）里按**文件名**找；内容搜索默认关 | 开（文件名） |
| 交接卡 / 审计 | 读写数据目录内文件 | 开 |

- 插件**不读**：其它插件的 DOM、你的密钥、浏览器凭据、白名单外的文件；
- 插件**不修改/不删除**既有会话；推送只发往沙盒会话（`[实验]` 前缀，可配白名单）；
- 「开新会话执行」会在你**本机**新建一个 CEO 预设会话，并只把任务写进它的第一句；该会话里读写文件/跑命令的权限弹窗由 DSH 宿主给出，你点了才生效。

## 三、什么时候会外发

只有一种情况：**你在聊天框里主动发消息**，内容会经 DSH 宿主交给模型服务（由你配置的模型供应商处理）。
看板刷新、提醒、台账、史官记录都是纯本地计算，不调用模型（CEO 分析除外——你点分析/问 CEO 时才会调用）。
角色聊天**只走绑定的真实会话**：会话不可用时插件只报错，不会自己直连模型代答。

## 四、权限与安全边界

- 插件没有删除文件的能力；写操作只发生在数据目录及其上一级的 `史官/`、`CEO/` 子目录；
- 需要越界读取时（例如让角色会话去读其它目录），走的是 **DSH 宿主的原生权限审批**，弹窗在会话里，由你决定；
- 角色会话禁用了团队 / 子代理类工具，避免"假装有团队"的胡话；
- 所有 HTTP 路由只监听本机回环地址上的 DSH 服务，不对外开端口。

## 五、隐私相关开关

| 配置 | 默认 | 作用 |
|---|---|---|
| `enabled.historian` | `true` | 史官总开关（0.47.0 起默认开；涉密环境请关掉） |
| `historian.scope.mode` | `all` | 发布默认读全部会话；`sandbox` 只读 `[实验]` + 角色会话（开发/测试推荐） |
| `historian.scope.prefixes` | `['[实验]']` | sandbox 模式的会话标题前缀 |
| `find.content` | `false` | 禁止按内容搜索文件 |
| `alarm.push.enabled` | `true` | 推送只发沙盒会话 |
| `dataDir` | 用户目录 | 数据放哪由你定 |

## 六、上报问题时的注意事项

开 issue 时请**不要**粘贴：真实会话正文、台账里的真实事项、`审计.jsonl` 原文、任何密钥。
需要复现时，用 `[实验]` 沙盒会话 + 演示数据，或只贴报错行。
